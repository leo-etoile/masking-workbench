# Conversation startup rule

- At the beginning of every new conversation for this repository, ask the user for the task name before starting any work.
- As soon as the user supplies the task name, use the Codex thread-title tool to rename the current task to that exact name.
- Treat the supplied task name as the canonical title of the work and use it consistently in the Codex task list, plans, progress updates, and summaries.
- Keep the opening question concise and ask it in the user's language (for example: "Please tell me the task name.").
- Do not begin implementation or investigation until the user supplies the task name.
